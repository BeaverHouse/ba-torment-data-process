# BA Torment 필터 데이터 명세

> [!NOTE]
> This document is written in Korean.

[BA Torment](https://bluearchive-torment.netlify.app/)에서 사용하는 필터 데이터 명세입니다.

## 데이터 형식

```json
{
  "filters": {
    "10000": { "53": 3, "54": 5 },
    "10001": { "53": 4, "54": 3 },
    "10002": { "53": 3, "54": 2 },
    "10003": { "51": 1, "52": 5, "53": 13, "54": 4 },
    "10004": { "53": 2 },
    "10005": { "51": 4, "52": 44, "53": 280, "54": 79 },
    "10006": { "51": 1, "52": 1, "53": 234, "54": 147 },
    "10007": { "51": 1, "52": 1, "53": 180, "54": 824 },
    "10008": { "52": 5, "53": 40, "54": 4 },
    "10010": { "53": 1 },
    "10011": { "30": 96, "40": 45, "51": 117, "52": 118, "53": 116, "54": 27 },
    // ...
    "26012": { "51": 2 },
    "26013": { "30": 2, "40": 2, "51": 28, "52": 12, "53": 1 },
    "26014": { "51": 7, "52": 3 },
    "26015": { "30": 1, "40": 2, "51": 2 }
  },
  "assistFilters": {
    "10039": { "53": 1 },
    "10043": { "52": 3, "53": 17, "54": 26 },
    "10049": { "53": 2 },
    "10084": { "52": 13333, "53": 1669, "54": 426 },
    "10085": { "30": 2, "40": 1, "51": 7, "52": 139, "53": 22, "54": 7 },
    // ...
    "20008": { "51": 2, "52": 21, "53": 12, "54": 18 },
    "20039": { "52": 27, "53": 24, "54": 75 }
  }
}
```

1. `filters`: 학생별 사용된 횟수를 저장한 Map입니다.
   - 키는 학생 ID, 값은 성급대로 사용된 횟수를 저장한 Map입니다.
     - Depth 2의 키는 2자리로 되어 있으며 첫 자리는 성급(1~5), 두 번째 자리는 전용 무기 성급(1~4)입니다.
     - 예를 들어, 4성이라면 "40", 전용무기 2성이라면 "52"가 됩니다.
2. `assist_filters`: 학생별 조력자로 사용된 횟수를 저장한 Map입니다.
   - 구성은 `filters`와 동일합니다.

필터 데이터는 3가지 형태로 저장됩니다.

- `v3/filter` 폴더는 파티 검색에 사용되는 필터 데이터입니다.
- `v3/lunatic-filter` 폴더는 LUNATIC 난이도에서의 통계 데이터입니다.
  - 사용률 분석을 위해 조력자는 `assist_filters`와 `filters`에 동시에 기록됩니다.
- `v3/nonlunatic-filter` 폴더는 TORMENT 난이도 이하에서의 통계 데이터입니다.
  - 사용률 분석을 위해 조력자는 `assist_filters`와 `filters`에 동시에 기록됩니다.
