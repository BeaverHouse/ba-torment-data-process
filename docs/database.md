# Database

We use PostgreSQL as our primary database.

1. All DB queries are generated by [sqlc](https://sqlc.dev).
2. See `internal/db/postgres/sql` directory for the DB schema and queries.
3. `*.go` files in `internal/db/postgres` directory are auto-generated files.

## How to install sqlc

1. Install [sqlc](https://sqlc.dev). In macOS, you can use Homebrew.

```bash
brew install sqlc
```

2. Run the following command:

```bash
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest
```
